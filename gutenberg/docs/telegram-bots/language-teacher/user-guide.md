# Language Teacher Bot User Guide

Learn how to use all features of your AI Language Teacher to maximize your language learning journey.

## 🎯 Getting Started

### First Time Setup

When you first start the bot, you'll go through a quick onboarding process:

1. **Language Selection** 
   - Choose your target language from available options
   - You can change this later in settings

2. **Level Assessment**
   - Take a quick placement test (5-10 questions)
   - Or manually select your level (A1-C2)
   
3. **Learning Goals**
   - Set daily practice goals (5-60 minutes)
   - Choose focus areas (conversation, grammar, vocabulary)
   
4. **Preferences**
   - Enable/disable voice features
   - Set notification preferences
   - Choose learning style

## 💬 Conversation Practice

### Starting a Conversation

Click **"Start Conversation"** or send `/practice` to begin:

```
Bot: Hi! Let's practice English. What did you do today?
You: I went to the park with my friends
Bot: That sounds nice! What did you do at the park? 🌳
You: We played football and had picnic
Bot: *We played football and had a picnic* 
     Great! Was the weather good for your picnic?
```

### Conversation Features

#### Natural Flow
- Bot maintains context throughout conversation
- Follow-up questions based on your responses
- Gradual topic transitions

#### Error Correction
- **Gentle corrections** shown in italics
- Explanations when needed
- No interruption to conversation flow

#### Vocabulary Building
- New words introduced contextually
- Definitions provided when needed
- Words added to your personal dictionary

### Conversation Tips

✅ **Do:**
- Speak naturally, don't worry about mistakes
- Ask questions when confused
- Try using new vocabulary
- Express opinions and feelings

❌ **Don't:**
- Use translation tools during practice
- Give one-word answers
- Be afraid of making errors
- Rush through conversations

## 📚 Homework & Exercises

### Exercise Types

#### Grammar Exercises
- **Fill in the blanks**: Complete sentences with correct forms
- **Multiple choice**: Choose the correct option
- **Sentence transformation**: Rewrite sentences
- **Error correction**: Find and fix mistakes

#### Vocabulary Practice
- **Word matching**: Match words with definitions
- **Context clues**: Guess meaning from context
- **Word families**: Learn related words
- **Collocations**: Common word combinations

#### Reading Comprehension
- **Short passages**: 100-200 words
- **News articles**: Current events
- **Stories**: Fiction and non-fiction
- **Comprehension questions**: Test understanding

#### Writing Practice
- **Guided writing**: Follow prompts
- **Free writing**: Express yourself
- **Email/letter writing**: Formal and informal
- **Essay practice**: Structured writing

### Adaptive Difficulty

The bot automatically adjusts exercise difficulty based on:
- Your current level
- Recent performance
- Time since last practice
- Specific weak areas

```
Performance → Difficulty Adjustment
90-100% correct → Increase difficulty
70-89% correct → Maintain level
50-69% correct → Slight decrease
<50% correct → Review and simplify
```

## 🎤 Voice & Pronunciation

### Using Voice Messages

1. **Record your message** in Telegram (hold microphone button)
2. **Send to bot** for analysis
3. **Receive feedback** on pronunciation

### Pronunciation Feedback

You'll receive detailed feedback including:

```
🎯 Pronunciation Score: 85/100

✅ Good pronunciation:
- "Hello" - Clear and accurate
- "Yesterday" - Good stress pattern

🔧 Areas to improve:
- "Th" sounds - Try placing tongue between teeth
- "R" sounds - Practice rolling slightly

💡 Tips:
- Practice "th" with "think, this, that"
- Listen to native speakers saying these words
```

### Voice Exercises

#### Shadowing
- Listen to bot's audio
- Repeat immediately after
- Match rhythm and intonation

#### Minimal Pairs
- Practice similar sounds
- "Ship" vs "Sheep"
- "Live" vs "Leave"

#### Tongue Twisters
- Build fluency
- Practice difficult sounds
- Improve articulation

## 💡 Tips for Success

### Daily Practice
1. **Consistency over intensity** - 10 minutes daily > 2 hours weekly
2. **Morning practice** - Better retention
3. **Review before bed** - Consolidate learning
4. **Use downtime** - Practice during commute

### Effective Learning
1. **Active participation** - Engage fully in conversations
2. **Make mistakes** - Essential for learning
3. **Use new words** - Apply immediately
4. **Think in target language** - Avoid translation

### Motivation Strategies
1. **Set realistic goals** - Start small, build up
2. **Track progress** - Celebrate improvements
3. **Join challenges** - Community motivation
4. **Reward yourself** - Celebrate milestones

### Common Issues

**Bot not responding?**
- Check internet connection
- Try `/start` to restart
- Clear chat and restart

**Exercises too hard/easy?**
- Adjust in `/settings`
- Complete level assessment again
- Manual difficulty override

**Voice not working?**
- Check microphone permissions
- Ensure voice messages enabled
- Try shorter recordings
