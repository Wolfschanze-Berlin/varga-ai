# Exercise Templates for Homework Teacher

## Vocabulary Exercises

### Multiple Choice Template
```
**Vocabulary Exercise**

What does '{word}' mean?

A) {option_1}
B) {option_2}  
C) {option_3}
D) {option_4}

*Points: {points}*
*Difficulty: {difficulty}*

Type the letter of your answer (A, B, C, or D).
```

### Fill-in-the-Blank Template
```
**Vocabulary Practice**

Complete the sentence with the correct word:

"{sentence_with_blank}"

Word bank: {word_options}

*Hint: {hint}*
```

### Word Association Template
```
**Word Association**

Which word is most closely related to '{target_word}'?

1. {option_1}
2. {option_2}
3. {option_3}
4. {option_4}

Think about the category or concept that '{target_word}' belongs to.
```

## Grammar Exercises

### Tense Completion Template
```
**Grammar Exercise: {tense_name}**

Complete the sentence with the correct form of the verb in parentheses:

"{sentence_template}"

Example: "I (eat) _____ breakfast every morning." → "I eat breakfast every morning."

*Remember: {grammar_rule}*
```

### Error Correction Template
```
**Find and Fix the Mistake**

The following sentence has a grammar error. Can you spot it and correct it?

❌ "{incorrect_sentence}"

What's wrong with this sentence? How would you fix it?

*Hint: Pay attention to {grammar_focus}*
```

### Sentence Building Template
```
**Build a Sentence**

Use these words to create a grammatically correct sentence:

Words: [{word_list}]

Rules:
- Use all the words
- Make sure the grammar is correct
- The sentence should make sense

*Bonus: Can you make two different sentences with the same words?*
```

## Reading Comprehension

### Short Passage Template
```
**Reading Comprehension**

Read the following text:

"{passage_text}"

Now answer these questions:

1. {question_1}
2. {question_2}  
3. {question_3}

*Take your time to read carefully before answering.*
```

### Multiple Choice Reading Template
```
**Reading Exercise**

Read the passage and choose the best answer:

"{reading_passage}"

**Question:** {comprehension_question}

A) {choice_a}
B) {choice_b}
C) {choice_c}
D) {choice_d}

*Look for key details in the text that support your answer.*
```

## Translation Exercises

### Phrase Translation Template
```
**Translation Practice**

Translate this phrase from {source_language} to {target_language}:

"{source_phrase}"

*Tips:*
- Think about the meaning, not word-by-word translation
- Consider cultural context
- Make it sound natural in {target_language}
```

### Sentence Translation Template
```
**Advanced Translation**

Translate this complete sentence:

"{source_sentence}"

*Challenge: Try to maintain the same tone and style in your translation.*
```

## Listening Comprehension (Text-Based)

### Audio Description Template
```
**Listening Practice** (Text-Based)

Imagine you hear this dialogue:

Person A: "{dialogue_line_1}"
Person B: "{dialogue_line_2}"
Person A: "{dialogue_line_3}"

Questions:
1. What is the main topic of conversation?
2. How does Person B feel about the situation?
3. What might happen next?

*Practice: Read this dialogue out loud to yourself!*
```

## Writing Prompts

### Beginner Writing Template
```
**Writing Exercise**

Write 3-5 sentences about: "{topic}"

Use these words in your writing:
- {required_word_1}
- {required_word_2}
- {required_word_3}

*Don't worry about perfect grammar - focus on expressing your ideas clearly!*
```

### Intermediate Writing Template
```
**Creative Writing**

Write a short paragraph (50-100 words) describing:

"{writing_prompt}"

Requirements:
- Use at least one {grammar_structure}
- Include vocabulary related to {topic_area}
- Make it interesting and personal

*Bonus: Can you use any idioms or expressions?*
```

## Exercise Feedback Templates

### Correct Answer Response
```
✅ **Excellent!** 

{explanation}

**Why this is correct:** {detailed_reasoning}

**Bonus tip:** {additional_information}

You're making great progress! Ready for the next challenge?
```

### Incorrect Answer Response
```
❌ **Not quite right, but good try!**

The correct answer is: **{correct_answer}**

**Here's why:** {explanation}

**What to remember:** {key_learning_point}

Don't worry - mistakes help us learn! Try another exercise?
```

### Partial Credit Response
```
⚡ **You're on the right track!**

You got {partial_score}% of this correct.

**What you did well:** {positive_feedback}

**To improve:** {constructive_feedback}

**Try this:** {specific_suggestion}

Keep going - you're improving! 🌟
```
